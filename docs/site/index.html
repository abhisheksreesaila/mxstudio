mxconsole · docs

Local AI on Modular MAX, made easy.

A convenience wrapper around MAX. One command gives you an OpenAI-compatible endpoint. Models load when they're called and unload when idle. If MAX can't run a model yet, mxconsole can port it.

git clone https://github.com/abhisheksreesaila/mxstudio.git
cd mxstudio
pixi install
pixi run mxc serve qwen2.5-0.5b

Why

Local AI, easy

mxc serve downloads, starts and prints a URL, a key and a curl line. Any OpenAI client works.

Many models, one endpoint

Each model starts on its first request and unloads when idle. GPU memory goes only to the models in use. Pin the ones you need kept loaded.

Safe to share

One revocable key per app. mxc expose serves it over HTTPS on your LAN.

Porting, fast

For an architecture MAX can't run yet, Claude Code writes a MAX version in a sandbox, and mxconsole checks it against the original. Behind the scenes.

The console at /console and the /admin routes only answer on this machine. From the LAN, only /v1/models, /v1/chat/completions, /v1/completions and /v1/embeddings get through.
