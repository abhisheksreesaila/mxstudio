Console tour

Every screen of the console

The console is the web page omxconsole serves at http://127.0.0.1:11435/console, only on the machine that runs it. It is plain pages. The top bar holds the logo, a breadcrumb, the Beacon, and Keys, Gateway, Security and Settings; My models is the home page, and each model has one page with four tabs. Pick a screen below. The numbered markers sit on the real controls; hover or tap one to see what it does and the mxc command that does the same thing.

Open it yourself: pixi run mxc console

    Screenshots are from a machine with an RTX 3090 (24 GB) named ablearn. Your models, numbers and host name will differ.
