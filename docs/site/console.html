Console tour

Every screen of the console

The console is the web page omxconsole serves at http://127.0.0.1:11435/console, only on the machine that runs it. Each screen is a blade. Blades open side by side from left to right, and older ones fold into a narrow rail so the newest one has room. Pick a screen below. The numbered markers sit on the real controls; hover or tap one to see what it does and the mxc command that does the same thing.

Open it yourself: pixi run mxc console

    Screenshots are from a machine with an RTX 3090 (24 GB) named ablearn. Your models, numbers and host name will differ.
