> What is MAX?
Modular MAX is a unified AI runtime engine...

Go on, ask.

Everything you need to know about the architecture, licensing, and hardware support.

Why MAX?

Modular's hardware graph engine provides sub-millisecond dispatch and bare-metal compilation with zero Python runtime overhead.

graph compiler <0.5ms dispatch
Why not Ollama or vLLM?

vLLM locks entire GPU memory tables immediately. Ollama is great for single runs but lacks dynamic multi-app API key control and automatic cold unloading.

vLLM: 100% VRAM pinned mxc: 0-mem idle drop
Does it need the cloud?
cloud_off 100% air-gapped local runtime.

No telemetry, no phoning home. Only the optional porting CLI utility connects to the Claude API to translate graph code.

What does porting cost?

The agent uses Claude 3.5 Sonnet to inspect PyTorch weights and synthesize Mojo kernel definitions.

$2–5 API cost 7–40 min runtime
